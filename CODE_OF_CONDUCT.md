# Code of Conduct

Be respectful, constructive, and welcoming. Discuss ideas and code without personal attacks. Harassment, discrimination, threats, unwanted sexual attention, and publishing another person's private information are not acceptable.

This applies to this project's issues, pull requests, and other project spaces. Maintainers may edit or remove harmful contributions and restrict participation to protect the community. Report abuse using GitHub's reporting tools; for concerns involving this project, you may also contact the maintainer through their GitHub profile.

Apply these standards consistently and respect reporters' privacy.
